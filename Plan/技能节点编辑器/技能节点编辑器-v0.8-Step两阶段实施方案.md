# 技能节点编辑器 v0.8 Step 两阶段实施方案

## 1. 结论先行

目前框架内**有**通用状态机基类与模块，可复用参考：

- `UnityProject/Assets/TEngine/Runtime/Module/FsmModule/IFsm.cs`
- `UnityProject/Assets/TEngine/Runtime/Module/FsmModule/FsmState.cs`
- `UnityProject/Assets/TEngine/Runtime/Module/FsmModule/Fsm.cs`
- `UnityProject/Assets/TEngine/Runtime/Module/FsmModule/FsmModule.cs`

但技能图 `Step + Snapshot/Restore + Trace + Lockstep` 不建议直接建立在该通用 FSM 之上，原因如下：

1. 通用 FSM 的驱动语义是 `OnUpdate(elapseSeconds, realElapseSeconds)`，而技能图需要 `Step(frameIndex, frameInput)`。
2. 通用 FSM 没有内建快照序列化与恢复协议。
3. 通用 FSM 没有执行事件流标准输出（Trace）接口。
4. 技能图节点是“数据驱动+可扩展节点类型”，按 FSM State 类拆分会导致状态类膨胀与维护成本上升。

建议：在 `UnityProject/Assets/GameScripts/HotFix/GameShared/SkillGraph` 内实现轻量执行状态机（Execution Session），生命周期可借鉴 FSM 思路，但不强耦合到 `FsmModule`。

交付节奏说明：Step A 产物需要在状态帧同步 `v0.5` 集成前提供。

---

## 2. 目标重述

`v0.8` 的目标保持不变：让技能图具备可逐帧驱动、可快照回滚、可确定性回放能力。

实施上拆成两步，第一步先把“可用内核”做出来，第二步再做“工程化加固”。

---

## 3. 两阶段实施

## Step A（v0.8-A）：Step 内核落地

### 范围

1. `RuntimeSkillGraph` 升级到 `0.8`。
2. 导出 `variables/defaultValue/syncMode`，并做基础合法性校验。
3. 新增会话化执行模型：`Initialize + Step + GetSnapshot + Restore`。
4. `Delay` 改为帧推进（基于剩余帧计数）。
5. `Action` 在锁步模式仅产生命令事件，不直接触发资源行为。
6. 新增最小可用 Trace 事件集：`NodeEnter/NodeExit/BlackboardSet/BranchTaken/CommandIssued/ExecutionEnd`。
7. 保留 `Run` 兼容入口（内部循环调用 `Step`）。

### 明确不做

1. 网络协议接入与联机层对接。
2. 增量快照压缩。
3. 完整可视化调试器。
4. 预测-校正（reconcile）。

### 验收

1. 同输入同种子重复执行，Trace 一致。
2. N 帧快照恢复后继续执行，与原时间线一致。
3. 旧 `Run` 调用链可工作（兼容层）。
4. 导出期能拦截基础非法配置（变量默认值非法、明显不安全节点配置）。

---

## Step B（v0.8-B）：同步与回滚工程化加固

### 范围

1. 完善不安全行为扫描与导出拦截规则（时间 API、异步资源、随机源使用策略）。
2. 完善快照协议版本化与跨版本兼容策略。
3. 增加回滚一致性专项测试矩阵（N 回滚到 M 再重放到 N）。
4. 完善 Trace 对比工具与错误定位信息（帧号、节点、字段差异）。
5. 评估并接入快照体积优化（增量快照或压缩）。
6. 补齐编辑器侧同步模式提示与校验反馈体验。

### 验收

1. 关键图回滚重放一致性稳定通过。
2. 导出拦截策略可覆盖既定不安全用法。
3. 快照恢复稳定且具备基础性能可接受性。

## 5. 关键设计约束（避免返工）

1. `Step` 必须是“单帧可返回”的非阻塞推进，不允许节点内部 `await` 长流程后才返回。
2. 所有可跨帧节点必须有可序列化局部状态。
3. 锁步模式下状态判定不得依赖真实时间或非确定性异步结果。
4. Trace 结构一旦发布，字段变更必须走版本化。

---

## 6. 里程碑建议

1. 里程碑 A1：Schema + 导出校验 + Blackboard 初始化。
2. 里程碑 A2：Runner Session + Delay 帧推进 + Run 兼容层。
3. 里程碑 A3：Action 命令化 + 最小 Trace + 基础一致性测试。
4. 里程碑 B1：回滚专项与导出安全规则补全。
5. 里程碑 B2：快照优化与编辑器同步提示完善。

---

## 7. 一句话建议

框架有通用 FSM，但技能图同步内核应在 `SkillGraph` 内部做“轻量会话状态机”；按两阶段推进可以显著降低一次性大改风险。
