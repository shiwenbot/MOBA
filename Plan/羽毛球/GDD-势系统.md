# 势系统（Momentum System）

> **状态**: 设计中
> **最后更新**: 2026-05-26
> **服务支柱**: 每一拍都有意义

## A. 概述

势系统量化"站位压力"。每个角色拥有一条 0~100 的势头条，代表其当前站位的稳固程度。每次击球都会改变双方的势头——精准回球夺势，仓促回球失势。当一方势头降至 0（站位崩溃），对手获得一次"终结窗口"，可以打出无法防守的扣杀终结回合。

这个系统让每次击球不仅是"打回去"，更是在争夺主动权。它回答了羽毛球最核心的博弈问题：什么时候该冒险进攻，什么时候该稳住防守。

## B. 玩家幻想

- **夺势时的感觉**：我每打一拍都能看到对手被逼得越来越远，他的身影在球场上狼狈奔跑，我知道再一拍就能终结他了
- **失势时的感觉**：我能感觉到自己被打开了——每接一拍都要多跑一步，回位越来越慢。我需要一拍高质量的高远球来喘口气
- **崩溃瞬间的感觉**：那一刻时间仿佛变慢，对手高高跃起，我知道这一拍我接不住了——但上一拍的失误才是真正的败因
- **反杀时的感觉**：我已经被打到崩溃边缘，但那一次完美的时机判定让我逆转了势头，从被追着打到追着别人打

## C. 详细设计

### 核心规则

**规则 1 — 势头是双边的**：回合进行中，双方各有一条独立的势头条。A 夺势不等于 B 自动失势（虽然大多数情况如此），两者的变化是分开计算的。

**规则 2 — 击球品质决定势头变化**：每次击球结束后（球飞过网），根据击球品质计算势头变化。击球品质由击球系统输出的三元组决定：
- **球路类型**：选择的球路类型（扣杀/吊球/平抽/高远球/网前球/挑球）
- **时机等级**：击球时机的精准程度（Perfect/Good/Late/Miss）
- **移动状态**：击球瞬间的移动状态（站定/移动/冲刺）

**规则 3 — 站位偏移是势头变化的放大器**：击球品质决定基础势头变化，但接球方的站位偏移量会放大这个变化。如果接球方已经被拉到角落，这一拍的势头变化会更大。

**规则 4 — 势头自然衰减**：如果回合中出现超过阈值时间的"无压力击球"（双方连续打高远球且站位良好），双方势头会缓慢回归中立值（50）。

**规则 5 — 站位崩溃触发终结窗口**：当一方势头降至 0 时，进入"站位崩溃"状态，持续固定时间窗口。在此窗口内，对手的扣杀变为"终结扣杀"（不可防守）。

**规则 6 — 势头归零不等于立刻输**：站位崩溃只给对手一次终结机会。如果对手没有在窗口内完成终结扣杀（比如选择了其他球路、或者时机没赶上），崩溃方恢复到最低安全势头（20），回合继续。

**规则 7 — 势头每回合重置**：每个新回合（发球开始时），双方势头重置为 50（中立）。

### 状态与转换

每个角色的势头状态机：

```
        [回合开始]
            │
            ↓
    ┌───────────────┐
    │   中立 Stable   │ ← 势头 20~80
    │   (默认状态)     │
    └───────┬───────┘
            │
      势头降至 20 以下
            │
            ↓
    ┌───────────────┐
    │   承压 Pressed  │ ← 势头 1~19
    │   (被压制状态)   │
    └───────┬───────┘
            │
        势头降至 0
            │
            ↓
    ┌───────────────────┐
    │  站位崩溃 Broken    │ ← 持续 T_终结窗口 秒
    │  (对手获得终结权)    │
    └───────┬───────────┘
            │
      ┌─────┴─────┐
      │           │
  终结成功     终结窗口过期
  或接球方     或对手未打终结扣杀
  得分           │
      │           │
      ↓           ↓
  [回合结束]  ┌────────────────┐
             │   恢复 Recover   │ ← 势头回升至 20
             │   (喘息恢复)     │    状态回到 Stable
             └────────────────┘
```

**状态说明**：

| 状态 | 势头范围 | 效果 | 合法转换 |
|------|---------|------|---------|
| Stable（中立） | 20~80 | 无特殊效果，正常击球 | → Pressed, → Recover, → 回合结束 |
| Pressed（承压） | 1~19 | 移动速度降低 10%；角色出现疲劳视觉表现（喘息动画） | → Broken, → Stable, → 回合结束 |
| Broken（崩溃） | 0 | 无法有效防守终结扣杀；屏幕边缘出现裂纹特效 | → 回合结束, → Recover |
| Recover（恢复） | 20 | 崩溃后的强制恢复状态，持续 1 秒内不可被再次崩溃 | → Stable |

### 与其他系统的交互

#### 击球系统

击球系统为势系统提供"击球品质"三元组：`(球路类型, 时机等级, 移动状态)`。势系统负责计算最终势头变化。

**时机判定等级**（由击球系统输出，4 档统一）：

| 判定 | TimingFactor | 说明 |
|------|-------------|------|
| Perfect（完美） | 1.5 | 在最佳时机窗口内击球 |
| Good（良好） | 1.0 | 在良好窗口内击球 |
| Late（迟） | 0.5 | 窗口边缘勉强击球 |
| Miss（挥空） | 0 | 未击中球，不产生球路势头变化，但有挥空惩罚 -15 |

**移动状态修正**（由击球系统输出）：

| 移动状态 | MovementFactor | 说明 |
|---------|---------------|------|
| 站定 | 1.0 | 原地击球，完整收益 |
| 移动 | 0.8 | 移动中击球，略有折损 |
| 冲刺 | 0.6 | 冲刺中击球，大幅折损 |

**球路 BaseShift 统一值**：

| 球路 | BaseShift_击球方 | BaseShift_接球方 | 说明 |
|------|------------------|------------------|------|
| 扣杀 Smash | -10 | -20 | 高风险：击球方自损，接球方重创 |
| 吊球 Drop | +8 | -12 | 中等奖励 |
| 高远球 Clear | +3 | -3 | 安全试探 |
| 平抽 Drive | +6 | -8 | 节奏快 |
| 网前球 Net | +10 | -15 | 高奖励高风险 |
| 挑球 Lift | +2 | -2 | 纯防守重置 |

#### 站位评估

站位评估系统为势系统提供"站位偏移值"，作为势头变化的放大器。

**理想站位点**：每个角色在球场中心有一个"理想回位点"，位于中场偏后三分之一处。每次击球后，角色需要回到这个位置准备下一次接球。

**站位偏移值计算逻辑**：
- 计算接球方当前位置到其理想回位点的距离
- 将距离归一化为 0~1 的偏移值（0 = 完美站位，1 = 极端偏移）
- 偏移值作为乘数放大势头变化：偏移越大，失势越多

**具体交互方式**：
- 击球系统完成一次击球后，向站位评估系统查询接球方的当前站位偏移值
- 势系统使用该偏移值计算最终势头变化
- 站位偏移值还会影响接球方下次击球的时机窗口大小（偏移越大窗口越小）

#### 反馈系统

势头变化需要多层反馈，确保"每一拍都有意义"的可感知性：

**势头条视觉反馈**：

| 势头范围 | 势头条外观 | 附加效果 |
|---------|-----------|---------|
| 60~80 | 蓝色平稳填充，轻微发光 | 无 |
| 40~60 | 蓝色正常填充 | 无 |
| 20~39 | 黄色，开始脉动 | 无 |
| 1~19 | 橙色，剧烈脉动，边缘模糊 | 角色移动速度 -10% |
| 0（崩溃） | 红色爆裂特效，屏幕边缘裂纹 | 终结窗口倒计时显示 |

**击球反馈（势头变化时）**：
- 势头变化 > 10：屏幕轻微震动 + 沉重击球音效
- 势头变化 > 20：屏幕中等震动 + "夺势"文字浮现
- 触发崩溃：时间减速 0.5 秒 + 崩溃音效 + 屏幕边缘碎裂

**势头条动画**：
- 势头变化时，条形不是线性填充，而是"冲击-回弹"动画，让每次变化有冲击感
- 势头条位置：角色头顶上方，跟随角色移动

## D. 公式

### 势头变化公式

击球后的势头变化由击球品质三元组、接球方站位和读招奖励共同决定。

```
Delta_M(击球方) = BaseShift_击球方 × TimingFactor × MovementFactor + ReadBonus × (1 - HabitPenalty)

Delta_M(接球方) = BaseShift_接球方 × TimingFactor × (1 + OffsetFactor)
```

**变量:**

| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 势头变化量 | Delta_M | 浮点 | -50~+25 | 一次击球导致的势头变化值 |
| 球路基础偏移（击球方） | BaseShift_击球方 | 浮点 | -10~+10 | 球路类型决定的击球方基础势头偏移 |
| 球路基础偏移（接球方） | BaseShift_接球方 | 浮点 | -20~-2 | 球路类型决定的接球方基础势头偏移（均为负值） |
| 时机修正系数 | TimingFactor | 浮点 | 0~1.5 | 击球时机判定的修正系数（Perfect=1.5, Good=1.0, Late=0.5, Miss=0） |
| 移动状态修正系数 | MovementFactor | 浮点 | 0.6~1.0 | 击球时移动状态的修正系数（站定=1.0, 移动=0.8, 冲刺=0.6） |
| 站位偏移因子 | OffsetFactor | 浮点 | 0.0~1.0 | 接球方偏离理想站位的程度 |
| 读招奖励 | ReadBonus | 浮点 | 0~10 | 来自模糊起手系统的读招夺势加成，默认为 0 |
| 习惯暴露惩罚 | HabitPenalty | 浮点 | 0~0.3 | 来自模糊起手系统的习惯暴露惩罚，默认为 0 |

**输出范围:** 单次 Delta_M_击球方 范围为 -15 到 +25（理论极端值），Delta_M_接球方 范围为 -50 到 -1
**实际常见范围:** Delta_M_击球方 -10 到 +15，Delta_M_接球方 -30 到 -2

**Miss（挥空）特殊情况**：Miss 时不走上述公式，击球方直接 Delta_M = -15（挥空惩罚），接球方 Delta_M = 0。

**示例 1 — 完美扣杀，对手在角落，站定击球：**
- 击球方选择扣杀：BaseShift_击球方 = -10，BaseShift_接球方 = -20
- 时机判定 Perfect：TimingFactor = 1.5
- 移动状态站定：MovementFactor = 1.0
- 接球方偏移大：OffsetFactor = 0.8
- 无读招奖励：ReadBonus = 0, HabitPenalty = 0
- 击球方 Delta_M = -10 × 1.5 × 1.0 + 0 × (1 - 0) = -15（扣杀让自己也失位）
- 接球方 Delta_M = -20 × 1.5 × (1 + 0.8) = -54 → clamp 后接球方势头降为 0（崩溃）
- 结果：击球方从 50 降到 35，接球方从 50 降到 0（崩溃触发）

**示例 2 — 良好高远球，双方中立站位，站定击球：**
- BaseShift_击球方 = +3，BaseShift_接球方 = -3
- TimingFactor = 1.0
- MovementFactor = 1.0
- OffsetFactor = 0.1（对手基本在位）
- ReadBonus = 0, HabitPenalty = 0
- 击球方 Delta_M = 3 × 1.0 × 1.0 + 0 = +3（稳妥夺势）
- 接球方 Delta_M = -3 × 1.0 × (1 + 0.1) = -3.3（轻微失势）
- 结果：击球方从 50 到 53，接球方从 50 到 46.7

**示例 3 — 迟滞吊球，冲刺中击球，对手在网前：**
- BaseShift_击球方 = +8，BaseShift_接球方 = -12
- TimingFactor = 0.5（Late）
- MovementFactor = 0.6（冲刺）
- OffsetFactor = 0.05（对手在网前，偏移小）
- ReadBonus = 0, HabitPenalty = 0
- 击球方 Delta_M = 8 × 0.5 × 0.6 + 0 = +2.4（收益很小）
- 接球方 Delta_M = -12 × 0.5 × (1 + 0.05) = -6.3（压力一般）
- 结果：几乎没变化，体现"仓促冲刺击球没有意义"

**示例 4 — 良好网前球，站定击球，带读招奖励：**
- BaseShift_击球方 = +10，BaseShift_接球方 = -15
- TimingFactor = 1.0（Good）
- MovementFactor = 1.0（站定）
- OffsetFactor = 0.6（对手在后场）
- ReadBonus = 5（成功读招），HabitPenalty = 0.1
- 击球方 Delta_M = 10 × 1.0 × 1.0 + 5 × (1 - 0.1) = 10 + 4.5 = +14.5（读招大幅夺势）
- 接球方 Delta_M = -15 × 1.0 × (1 + 0.6) = -24（被重创）
- 结果：击球方从 50 到 64.5，接球方从 50 到 26（进入承压边缘）

**示例 5 — Miss（挥空）：**
- 击球方 Delta_M = -15（固定挥空惩罚）
- 接球方 Delta_M = 0
- 结果：击球方从 50 到 35，接球方不变

### 站位偏移因子公式

```
OffsetFactor = clamp(Distance / MaxDistance, 0.0, 1.0)
```

**变量:**

| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 当前距理想点距离 | Distance | 浮点 | 0.0~MaxDistance | 角色当前位置到理想回位点的距离（米） |
| 最大参考距离 | MaxDistance | 浮点 | 5.0（常量） | 球场对角线参考距离，超出视为最大偏移 |

**输出范围:** 0.0（完美站位）到 1.0（极端偏移）

### 势头自然衰减公式

```
M(t) = M(t-1) + DecayRate × dt    (当双方都处于 Stable 且连续 N 拍无人失势时生效)
```

**变量:**

| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 当前势头 | M(t) | 浮点 | 0~100 | 角色当前势头值 |
| 衰减速率 | DecayRate | 浮点 | -2.0~+2.0 | 每秒势头向 50 回归的速率 |
| 时间步长 | dt | 浮点 | >0 | 距上次更新的时间（秒） |
| 触发拍数阈值 | N | 整数 | 4 | 连续几拍无显著失势后开始衰减 |

**衰减规则**：
- 势头 > 50 时：DecayRate = -2.0（缓慢下降）
- 势头 < 50 时：DecayRate = +2.0（缓慢回升）
- 势头 = 50 时：不衰减

### 终结窗口时长

```
T_终结窗口 = T_基础 + Bonus_承压时间
```

**变量:**

| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 终结窗口总时长 | T_终结窗口 | 浮点 | 2.0~4.0 | 崩溃后对手可执行终结的时间（秒） |
| 基础窗口时长 | T_基础 | 浮点 | 2.0（常量） | 最基础的终结窗口时长 |
| 承压时间加成 | Bonus_承压时间 | 浮点 | 0.0~2.0 | 对手承压越久，窗口越长 |

**Bonus_承压时间 计算**：
- 对手在 Pressed 状态下每持续 2 秒，Bonus +0.5，上限 2.0 秒
- 目的：长期压制的玩家获得更充裕的终结时间

**示例**：
- 对手刚进入 Pressed 就崩溃：T = 2.0 + 0.0 = 2.0 秒
- 对手在 Pressed 持续了 4 秒后崩溃：T = 2.0 + 1.0 = 3.0 秒
- 对手在 Pressed 持续了 8 秒后崩溃：T = 2.0 + 2.0 = 4.0 秒

## E. 边界情况

- **如果回合第一拍就触发站位崩溃（如发球直接扣杀）**: 势头系统不激活，发球阶段双方势头锁定在 50，直到发球完成后的第一次正常击球才开始计算势头。理由：发球是回合的起点，不应该有势头博弈。

- **如果双方同时降至 0（理论上极端情况）**: 先降至 0 的一方崩溃，另一方保持 1 点势头并进入承压状态。理由：同时崩溃会导致混乱，先触发者承担后果。

- **如果在终结窗口内球触网或出界**: 终结窗口立即结束，崩溃方恢复至 20 势头，回合按正常出界/触网规则判分。理由：终结者的失误不应该被崩溃机制惩罚。

- **如果终结窗口内对手选择非扣杀球路（如吊球）**: 终结机会浪费，窗口结束后崩溃方恢复至 20 势头。但该次击球的正常势头变化照常计算。理由：鼓励终结者把握机会，但不强制必须扣杀。

- **如果在崩溃状态下接球方提前击球（截击）**: 截击视为 Late 击球（TimingFactor = 0.5），但成功截击会让势头从 0 回升至 15 并脱离崩溃。理由：奇迹般的截击应该被奖励，给崩溃方一线生机。

- **如果势头超过 100 或低于 0**: 强制 clamp 到 [0, 100]。势头为 0 时不再继续扣减。理由：数值溢出会导致系统行为不可预测。

- **如果角色在 Recover 状态下再次被大幅扣减势头**: 势头值最低维持在 20，不会在 Recover 期间再次触发崩溃。Recover 状态持续 1 次击球交换后解除。理由：连续崩溃体验过于挫败，需要给玩家喘息空间。

- **如果回合因超时或其他规则结束（非崩溃终结）**: 势头系统不再计算，回合按正常规则判分。势头值不跨回合保留。理由：每个回合是独立的叙事单元。

- **如果一方始终打高远球形成无限循环**: 连续 4 拍（N = 4）双方无显著失势后，自然衰减机制激活，双方势头向 50 回归。如果一方试图利用高势头无限拖延，势头会自然衰减，防止"烧时间"策略。理由：回合需要有进展方向。

- **如果在网络延迟环境下势头计算不一致**: 以服务端（或帧同步主机）的计算结果为准，客户端只做视觉预测。理由：一致性高于即时反馈。

## F. 依赖

| 系统 | 关系 | 类型 | 说明 |
|------|------|------|------|
| 击球系统 | 上游 | **硬依赖** | 提供击球品质三元组（球路类型、时机等级、移动状态），没有击球就没有势头变化 |
| 时机窗口系统 | 上游（间接） | **硬依赖** | 通过击球系统传递时机判定结果 |
| 站位评估 | 上游 | **硬依赖** | 提供接球方站位偏移值，影响势头变化幅度 |
| 回合与裁判 | 上游 | **硬依赖** | 提供回合开始/结束事件，控制势头重置时机 |
| 模糊起手系统 | 上游 | **软依赖** | 提供 ReadBonus（读招夺势加成 0~10）和 HabitPenalty（习惯暴露惩罚 0~0.3），默认值分别为 0 和 0 |
| 反馈系统 | 下游 | **软依赖** | 势系统提供势头变化事件，反馈系统决定视觉表现 |
| AI 系统 | 下游 | **软依赖** | 势系统提供势头状态，AI 据此调整策略（崩溃时更激进） |
| 相机系统 | 下游 | **软依赖** | 崩溃时相机可以拉远/变焦增强戏剧感 |
| 球场与球物理 | 上游 | 软依赖 | 提供球场尺寸用于计算站位偏移距离 |
| 角色移动 | 上游 | 软依赖 | 提供角色实时位置，承压状态影响移动速度 |

## G. 调节旋钮

### G1. 势头变化幅度全局缩放

**参数名**: `MomentumScale`
**类型**: 浮点 | **默认值**: 1.0 | **安全范围**: 0.5~2.0

所有 Delta_M 乘以此值。
- **太高 (> 1.5)**：每拍势头变化剧烈，3~4 拍就崩溃，回合太短，博弈来不及展开。玩家感觉"还没开始就结束了"。
- **太低 (< 0.7)**：需要 15 拍以上才崩溃，回合冗长乏味，"势"的存在感薄弱，玩家觉得"打不打都一样"。

### G2. 扣杀基础自损

**参数名**: `SmashSelfDamage`
**类型**: 浮点 | **默认值**: -10 | **安全范围**: -20~0

扣杀时击球方自身的基础势头变化。
- **太高 (接近 0)**：扣杀无代价，变成每拍最优选择，球路多样性消失，所有回合变成对扣。
- **太低 (< -15)**：扣杀代价太大，无人愿意扣杀，终结手段缺失，回合无法正常结束。

### G3. 站位偏移放大上限

**参数名**: `OffsetCap`
**类型**: 浮点 | **默认值**: 1.0 | **安全范围**: 0.3~2.0

OffsetFactor 的 clamp 上限。
- **太高 (> 1.5)**：只要对手偏离站位就能造成毁灭性打击，移动慢的角色过于吃亏，角色平衡性崩坏。
- **太低 (< 0.5)**：站位几乎不影响势头，"夺势"失去空间博弈维度，退化成纯时机判定游戏。

### G4. 终结窗口基础时长

**参数名**: `FinisherWindowBase`
**类型**: 浮点 | **默认值**: 2.0 | **安全范围**: 1.0~4.0

站位崩溃后对手可执行终结的基础时间（秒）。
- **太高 (> 3.0)**：终结太容易，崩溃几乎等于输，防守方没有翻盘感，挫败感强。
- **太低 (< 1.5)**：终结窗口太紧，很多时候来不及反应和移动到位，崩溃不等于惩罚，势头系统的威慑力消失。

### G5. 崩溃恢复势头值

**参数名**: `RecoveryMomentum`
**类型**: 整数 | **默认值**: 20 | **安全范围**: 10~30

崩溃或终结失败后恢复到的势头值。
- **太高 (> 25)**：崩溃后几乎立刻回到安全区，崩溃的惩罚感不足，"夺势"的意义被稀释。
- **太低 (< 15)**：崩溃后仍然在 Pressed 边缘，极易再次崩溃，形成"崩溃→恢复→立刻再崩溃"的恶性循环。

### G6. 自然衰减触发拍数

**参数名**: `DecayRallyThreshold`
**类型**: 整数 | **默认值**: 4 | **安全范围**: 2~8

连续多少拍无显著失势后开始自然衰减。
- **太高 (> 6)**：衰减触发太慢，一方占据势头优势后可以无限保持，回合节奏停滞。
- **太低 (< 3)**：衰减太快，夺势成果容易被抹平，玩家觉得"夺了也白夺"，削弱进攻积极性。

### G7. 承压状态移动速度惩罚

**参数名**: `PressedSpeedPenalty`
**类型**: 浮点 | **默认值**: 0.10 | **安全范围**: 0.0~0.25

承压状态下的移动速度降低比例。
- **太高 (> 0.20)**：承压方几乎无法跑位，形成"失势→跑不动→更失势"的死亡螺旋。
- **太低 (< 0.05)**：承压状态几乎无体感差异，玩家不觉得"被压制"，状态切换的存在感薄弱。

### G8. Perfect 判定倍率

**参数名**: `PerfectMultiplier`
**类型**: 浮点 | **默认值**: 1.5 | **安全范围**: 1.2~2.0

完美时机判定的势头变化放大系数。
- **太高 (> 1.8)**：完美判定收益过大，游戏变成"拼时机精度"，偏离"读招即玩法"的设计支柱。
- **太低 (< 1.2)**：完美和良好差异太小，玩家没有动力追求完美时机，时机窗口系统失去意义。

### G9. 读招夺势加成

**参数名**: `ReadBonus`
**类型**: 浮点 | **默认值**: 0 | **安全范围**: 0~10

成功读招带来的额外势头加成。来自模糊起手系统。
- **太高 (> 7)**：读招收益过大，游戏变成"猜拳"，球路选择和时机判定的重要性被削弱。
- **太低 (< 3)**：读招加成几乎无体感，模糊起手系统的"读招即玩法"支柱失去意义。

### G10. 习惯暴露惩罚

**参数名**: `HabitPenalty`
**类型**: 浮点 | **默认值**: 0 | **安全范围**: 0~0.3

习惯性球路选择被读出后的读招奖励衰减系数。来自模糊起手系统。
- **太高 (> 0.2)**：惩罚过重，导致读招加成被大幅削弱，读招收益不稳定。
- **太低 (< 0.05)**：惩罚几乎无影响，玩家不会因为习惯性打法而付出代价。

## H. 验收标准

- **给定** 双方势头均为 50 且处于 Stable 状态，**当** 击球方以 Perfect 时机站定打出扣杀且接球方站位偏移因子为 0.8，**则** 击球方 Delta_M = -10 × 1.5 × 1.0 = -15（势头降至 35），接球方 Delta_M = -20 × 1.5 × 1.8 = -54（势头降至 0，触发崩溃）。

- **给定** 接球方势头为 15（Pressed 状态），**当** 击球方以 Good 时机站定打出吊球且接球方偏移因子为 0.6，**则** 接球方 Delta_M = -12 × 1.0 × 1.6 = -19.2（势头从 15 降至 0 以下，进入 Broken 状态）。

- **给定** 一方处于 Broken 状态且终结窗口为 2.5 秒，**当** 终结方在窗口内以任何时机打出扣杀，**则** 回合以终结方得分结束，屏幕显示终结演出效果。

- **给定** 一方处于 Broken 状态，**当** 终结窗口过期且终结方未打出扣杀，**则** 崩溃方势头恢复至 20（RecoveryMomentum），状态转为 Stable，回合继续。

- **给定** 双方处于 Stable 状态且势头均为 65，**当** 连续 4 拍双方均以 Good 时机站定打高远球且站位偏移均 < 0.1，**则** 双方势头开始以每秒 2 点的速率向 50 回归。

- **给定** 一方势头为 50，**当** 新回合开始（发球），**则** 双方势头均重置为 50，无论上一回合的势头值。

- **给定** 一方处于 Recover 状态（势头 20），**当** 对手以 Perfect 扣杀站定击球且站位偏移因子 0.9，**则** 该方势头最低降至 20，不会再次触发崩溃（Recover 期间崩溃保护生效）。

- **给定** 一方势头为 12（Pressed），**当** 该方以 Perfect 时机站定打出高远球且回球到位，**则** 该方 Delta_M = +3 × 1.5 × 1.0 = +4.5（势头从 12 升至 16.5），仍处于 Pressed 状态。

- **给定** 一方处于 Broken 状态，**当** 对手选择吊球而非扣杀，**则** 终结窗口正常过期，崩溃方恢复至 20，吊球的正常势头变化照常计算。

- **给定** 一方处于 Broken 状态，**当** 对手的扣杀出界，**则** 回合以出界方失分结束（正常出界规则优先），崩溃方势头不恢复（回合已结束）。

- **给定** 双方同时接近 0 势头（极端情况），**当** 一次击球同时将双方推至 0 以下，**则** 先到达 0 的一方（根据帧计算顺序）进入 Broken，另一方保持在 1 并进入 Pressed。

- **给定** 一方处于 Pressed 状态（势头 8），**当** 角色移动，**则** 移动速度比 Stable 状态慢 10%（PressedSpeedPenalty），视觉上角色有疲劳表现。

- **给定** 双方势头均为 50，**当** 击球方 Miss（挥空），**则** 击球方 Delta_M = -15（固定挥空惩罚），势头降至 35，接球方势头不变。

- **给定** 双方势头均为 50，**当** 击球方以 Good 时机站定打出网前球且 ReadBonus = 5、HabitPenalty = 0，**则** 击球方 Delta_M = 10 × 1.0 × 1.0 + 5 × (1 - 0) = +15（势头升至 65）。

- **给定** 双方势头均为 50，**当** 击球方以 Good 时机站定打出网前球且 ReadBonus = 5、HabitPenalty = 0.3，**则** 击球方 Delta_M = 10 × 1.0 × 1.0 + 5 × (1 - 0.3) = 13.5（势头升至 63.5，习惯暴露导致读招收益降低）。

- **给定** 双方势头均为 50，**当** 击球方以 Good 时机冲刺打出吊球，**则** 击球方 Delta_M = 8 × 1.0 × 0.6 = +4.8（冲刺中击球收益大幅折损）。

- **给定** 双方势头均为 50，**当** 击球方以 Good 时机站定打出挑球，**则** 击球方 Delta_M = +2 × 1.0 × 1.0 = +2（最小夺势，纯防守重置），接球方 Delta_M = -2 × 1.0 × 1.0 = -2。
