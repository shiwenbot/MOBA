# 击球系统（Shot System）

> **状态**: 设计中
> **最后更新**: 2026-05-26
> **服务支柱**: 每一拍都有意义 + 手机上也能精妙操作 + 读招即玩法

## A. 概述

击球系统是玩家与游戏交互的核心层。玩家通过"方向输入 + 单击球键"的简洁操作，在时机窗口内完成击球。击球瞬间的方向决定球路类型（高远球、吊球、扣杀、平抽、网前球、挑球），击球时机决定球的质量（Perfect / Good / Late / Miss）。每种球路有独特的弹道参数和硬直时间，击球系统产出"击球品质三元组"（球路类型、时机等级、移动状态）供势系统计算势头变化，形成"读招 → 选球路 → 抢时机 → 看结果"的核心博弈循环。

## B. 玩家幻想

- "我读懂了他的站位——他偏向左侧，一记吊球打向右前方，他来不及了"
- "完美时机扣杀的那一下，屏幕一震，球像子弹一样砸下去"
- "他以为我要扣杀，引拍动作一模一样，结果我轻放了一个网前球"
- "被动救球打出一记高远球，终于有时间跑回中心了"
- "他连续三拍都打平抽，节奏越来越快，我算准了他会继续，一记吊球打断了他的节奏"

## C. 详细设计

### 核心规则

1. **击球触发条件**：球进入角色的击球范围（水平距离 + 垂直高度均满足），且角色处于可击球状态（Idle / Moving，非 Startup / Swinging / Recovery / Stun）
2. **输入判定时机**：球进入击球范围的第一帧开启"挥拍窗口"，玩家在窗口内按下击球键即触发击球判定
3. **球路由方向决定**：击球键按下瞬间的方向输入（后/前/下/侧/无）映射为对应球路；部分球路有额外位置/高度条件
4. **时机决定质量**：击球键按下时机相对于"最佳击球点"的偏移，决定 Perfect / Good / Late 三档
5. **未击球后果**：挥拍窗口关闭后球仍未被击中，触发 Miss，角色进入短暂硬直

### 球路详细参数

> 基准值基于"标准角色"（无属性加成），实际值受角色属性和时机修正影响。
> 球场坐标系：XZ 为水平面，X 为左右，Z 为前后（正方向指向对手半场），Y 为高度。
> **势头变化由势系统根据球路类型、时机等级、移动状态统一计算，击球系统不直接产出夺势值。**

| 参数 | 高远球 Clear | 吊球 Drop | 扣杀 Smash | 平抽 Drive | 网前球 Net | 挑球 Lift |
|------|-------------|-----------|------------|------------|------------|-----------|
| **触发输入** | 后方向 + 击球 | 前方向 + 击球 | 下方向 + 击球 | 侧方向 + 击球 | 近网区域 + 击球（无方向/任意） | 后方向 + 击球（球低位） |
| **额外条件** | 无 | 无 | 球高度 > 肩高 | 无 | 角色距网 < 2.0m | 球高度 < 腰高 |
| **初速度（水平）** | 14 m/s | 6 m/s | 22 m/s | 18 m/s | 4 m/s | 10 m/s |
| **发射角（仰角）** | 55° | 20° | -15°（下压） | 10° | 35° | 60° |
| **飞行时间** | 1.2 ~ 1.5s | 0.5 ~ 0.7s | 0.3 ~ 0.4s | 0.4 ~ 0.6s | 0.6 ~ 0.8s | 1.3 ~ 1.6s |
| **落点深度** | 后场 80%~95% | 前场 5%~15% | 中前场 40%~60% | 中场 50%~70% | 前场 5%~10% | 后场 75%~90% |
| **硬直时间** | 0.3s | 0.25s | 0.5s | 0.2s | 0.35s | 0.3s |
| **风险等级** | 低 | 中 | 高 | 中 | 高 | 低 |

**弹道模型说明**：
- 羽毛球有极高的空气阻力，水平速度按指数衰减（每秒衰减约 60%）
- 垂直方向受重力影响（g = 9.8 m/s²），但羽毛球还有额外的竖直阻力
- 扣杀的负仰角表示球从高处向下击出，初始就有向下的垂直分量

### 击球条件

每种球路除了方向输入外，还有位置和球高度的要求：

| 球路 | 角色位置要求 | 球高度要求 | 不满足条件时 |
|------|-------------|-----------|-------------|
| 高远球 Clear | 任意（己方半场内） | 任意 | — |
| 吊球 Drop | 任意（己方半场内） | 任意 | — |
| 扣杀 Smash | 任意（己方半场内） | 球 Y > 角色肩高（1.5m） | 退化为平抽 Drive |
| 平抽 Drive | 任意（己方半场内） | 腰高 < 球 Y < 肩高 | — |
| 网前球 Net | 角色距网 < 2.0m | 任意 | 退化为吊球 Drop |
| 挑球 Lift | 任意（己方半场内） | 球 Y < 角色腰高（0.8m） | 退化为高远球 Clear（略弱） |

**退化规则优先级**：当多个球路条件都不满足时，按 高远球 → 平抽 → 吊球 的顺序回退。确保玩家永远能打出一记球，不会出现"按了击球但无反应"的情况。

**击球范围**：
- 水平半径：1.2m（以角色中心为圆心）
- 高度范围：0.0m ~ 2.5m（低于膝盖无法击球，触发 Miss）
- 击球范围在角色移动中缩小至 0.9m（精度惩罚）

### 时机系统

球进入击球范围后，开启挥拍窗口。窗口总时长 500ms，分为四个区间：

| 时机 | 窗口位置 | 时长 | 效果 |
|------|---------|------|------|
| **Perfect** | 球距最佳击球点 ±50ms | 100ms | 球速 ×1.3，方向精准（±0°偏移），TimingFactor = 1.5 |
| **Good** | Perfect 之后 ±100ms | 200ms | 球速 ×1.0，方向轻微偏移（±5°），TimingFactor = 1.0 |
| **Late** | Good 之后 ±100ms | 200ms | 球速 ×0.7，方向偏移（±15°），TimingFactor = 0.5 |
| **Miss** | 窗口关闭仍未击球 | — | 挥空，硬直 0.6s，不产出三元组，直接触发 Stun |

**移动状态**（击球瞬间的角色速度决定）：

| 移动状态 | 条件 | MovementFactor |
|----------|------|----------------|
| 站定 | 角色速度 < 0.5 m/s | 1.0 |
| 移动中 | 0.5 m/s ≤ 角色速度 < 4.0 m/s | 0.8 |
| 冲刺中 | 角色速度 ≥ 4.0 m/s | 0.6 |

**击球品质三元组**：每次成功击球（非 Miss）产出 `(球路类型, 时机等级, 移动状态)`，传递给势系统用于计算势头变化。

**时机判定流程**：
1. 球飞行进入击球范围 → 挥拍窗口开启
2. "最佳击球点" = 球到达角色正前方最近点的时刻
3. Perfect 窗口以最佳击球点为中心
4. Good 窗口紧接 Perfect 两侧
5. Late 窗口紧接 Good 两侧
6. 窗口期间玩家按下击球键 → 取对应时机档位
7. 窗口结束未按键 → Miss

**时机窗口可视化**：
- 球进入击球范围时，角色脚下出现"时机环"
- 时机环从外圈向内收缩，收缩到最小时 = Perfect 中心点
- Perfect 命中时环闪光 + 角色"充能爆发"特效；Good 命中时环消散；Late 命中时环变暗红
- Miss 时机环碎裂

### 状态与转换

角色击球相关的状态机：

```
[Idle] ──球进入范围──→ [Ready]
  │                        │
  │                       │ 按击球键
  ↓                        ↓
[Startup] ──引拍完成──→ [Swinging] ──判定完成──→ [Contact] ──球出手──→ [Recovery] ──恢复完成──→ [Idle]
  │                                                     │
  │ 被对手快球打断                                       │ 可被新球打断
  ↓                                                     ↓
[Stun] ──0.2s后──→ [Idle]                              [Ready]

  另：Miss 从 Ready 直接进入 Stun(0.6s) → Idle
```

**各状态说明**：

| 状态 | 持续时间 | 可否移动 | 可否击球 | 说明 |
|------|---------|---------|---------|------|
| Idle | 无限 | 是 | 否 | 站立/移动中，等待球 |
| Ready | 500ms（挥拍窗口） | 否（滑步微调 ≤ 0.3m） | 是 | 球进入范围，准备击球 |
| Startup | 由模糊起手系统控制 | 否 | 否 | 引拍阶段，可被对手快球打断；时长按球路组不同：高球路组约 450ms，中球路组约 200ms，低球路组约 100ms |
| Swinging | 0.15s | 否 | 否 | 挥拍动画前摇，不可取消；此阶段对应模糊起手的"揭示期" |
| Contact | 0.05s | 否 | 否 | 球拍接触球的一帧，球获得初速度 |
| Recovery | 球路决定（0.2s ~ 0.5s） | 否 | 否 | 击球后硬直，角色无法行动 |
| Stun | 0.2s（被打断）/ 0.6s（Miss） | 否 | 否 | Startup 被打断或 Miss 后的惩罚状态 |

**关键约束**：
- Ready 状态下角色无法大范围移动（只能微调），这确保了"提前到位"是博弈的一部分
- Startup 阶段由模糊起手系统控制视觉表现（模糊期 + 渐明期），不同球路组的引拍时长不同
- Swinging 前摇 0.15s 是不可取消的，这意味着击球决策一旦做出就不能反悔
- Recovery 期间如果新球进入范围，状态不会转为 Ready，确保连续击球间必须有间隔

**Startup 阶段打断规则**：
- Startup 阶段如果对手的球进入击球范围 → 中断引拍，进入 Stun（200ms）
- 打断条件：角色处于 Startup 状态时，对手的球飞入角色击球范围（水平距离 + 垂直高度均满足）
- Swinging 阶段不可被打断（已过揭示期，挥拍动作不可逆）
- 打断后角色进入 Stun，对手获得节奏优势（势系统可据此计算额外的势头变化）

### 与其他系统的交互

**势系统**：
- 每次成功击球产出"击球品质三元组"：`(球路类型, 时机等级, 移动状态)`
- 时机等级提供 TimingFactor（Perfect=1.5, Good=1.0, Late=0.5）
- 移动状态提供 MovementFactor（站定=1.0, 移动中=0.8, 冲刺中=0.6）
- 势系统根据三元组统一计算势头变化，击球系统不直接计算夺势值
- Miss 不产出三元组，势系统自行处理 Miss 对势头的影响

**模糊起手**（软依赖）：
- 击球系统的 Startup 阶段由模糊起手系统控制视觉表现
- Startup 的"模糊期 + 渐明期"对应模糊起手的不确定性展示
- Swinging 的 0.15s 对应模糊起手的"揭示期"，球路差异在此阶段才完全暴露
- 不同球路组的 Startup 时长不同（高球路组约 450ms，中球路组约 200ms，低球路组约 100ms）

**角色移动**：
- 站定击球（速度 < 0.5m/s 时按下击球键）：精度 ×1.0，MovementFactor = 1.0
- 移动中击球（速度 ≥ 0.5m/s 时按下击球键）：精度 ×0.8，方向偏移增加 ±8°，MovementFactor = 0.8
- 冲刺中击球（速度 ≥ 4.0m/s 时按下击球键）：精度 ×0.6，方向偏移增加 ±15°，MovementFactor = 0.6
- 移动中击球范围缩小：水平半径从 1.2m 降至 0.9m

**反馈系统**（软依赖）：
- Perfect 时机：屏幕微震（强度 3/5）+ 白色闪光 + 清脆"啪"音效 + 球轨迹高亮
- Good 时机：正常击球音效 + 轻微震动（强度 1/5）
- Late 时机：闷响音效 + 无震动 + 球轨迹变暗
- Miss：挥空"呼"声 + 角色踉跄动画 + 屏幕轻微晃动
- 扣杀 Perfect 额外：慢动作 0.2s（Time.timeScale = 0.3）+ 屏幕强震（强度 5/5）+ 红色冲击波特效
- 网前球 Perfect 额外：球过网时产生涟漪特效

## D. 公式

### 球速计算

```
ActualSpeed = BaseSpeed × TimingMultiplier × MovementMultiplier × CharacterPowerModifier
```

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 球路基础速度 | BaseSpeed | float | 4 ~ 22 m/s | 由球路类型决定 |
| 时机修正系数 | TimingMultiplier | float | 0.7 ~ 1.3 | Perfect=1.3, Good=1.0, Late=0.7 |
| 移动修正系数 | MovementMultiplier | float | 0.6 ~ 1.0 | 站定=1.0, 移动=0.8, 冲刺=0.6 |
| 角色力量修正 | CharacterPowerModifier | float | 0.9 ~ 1.1 | 角色属性差异，白盒阶段固定 1.0 |

**输出范围:** 2.52 m/s（Late + 冲刺 + 最弱角色 + 网前球）到 28.6 m/s（Perfect + 站定 + 最强角色 + 扣杀）
**示例:** 扣杀 + Perfect + 站定 + 标准角色 = 22 × 1.3 × 1.0 × 1.0 = 28.6 m/s

### 方向偏移计算

```
ActualAngleDeviation = BaseAngleDeviation × MovementAnglePenalty + Random(0, 1) × TimingAngleNoise
```

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 基础方向偏移 | BaseAngleDeviation | float | 0° ~ 15° | Perfect=0°, Good=5°, Late=15° |
| 移动角度惩罚 | MovementAnglePenalty | float | 1.0 ~ 3.0 | 站定=1.0, 移动=2.0, 冲刺=3.0 |
| 时机角度噪声 | TimingAngleNoise | float | 0° ~ 5° | Perfect=0°, Good=2°, Late=5° |

**输出范围:** 0°（Perfect + 站定）到 50°（Late + 冲刺 + 最大噪声）
**示例:** Late + 移动中击球 = 15 × 2.0 + random × 5 = 30° ~ 35° 偏移

### 势头变化说明

> **注意**：势头变化由势系统统一计算，击球系统不直接计算夺势值。
>
> 击球系统向势系统提供的输入为**击球品质三元组**：`(球路类型, 时机等级, 移动状态)`
>
> - 球路类型：决定球路基础势头权重（如扣杀高权重、挑球低权重）
> - 时机等级：TimingFactor（Perfect=1.5, Good=1.0, Late=0.5）
> - 移动状态：MovementFactor（站定=1.0, 移动中=0.8, 冲刺中=0.6）
>
> 势系统根据自身公式，综合三元组和当前势状态计算最终的势头变化值。

### 飞行时间估算

```
FlightTime = (2 × InitialVerticalSpeed) / (Gravity + VerticalDrag × InitialVerticalSpeed)
```

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 初始垂直速度 | InitialVerticalSpeed | float | 1 ~ 18 m/s | 由初速度和发射角计算：Speed × sin(Angle) |
| 重力加速度 | Gravity | float | 固定 9.8 m/s² | 物理常量 |
| 垂直阻力系数 | VerticalDrag | float | 0.3 ~ 0.8 | 羽毛球的空气阻力特性 |

**输出范围:** 0.25s（扣杀，极短）到 1.8s（挑球/高远球，较长）
**示例:** 高远球初始垂直速度 = 14 × sin(55°) = 11.47 m/s，FlightTime ≈ 2 × 11.47 / (9.8 + 0.5 × 11.47) ≈ 1.5s

### 硬直时间计算

```
ActualRecovery = BaseRecovery × TimingRecoveryMultiplier
```

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 球路基础硬直 | BaseRecovery | float | 0.2 ~ 0.5s | 由球路类型查表 |
| 时机硬直修正 | TimingRecoveryMultiplier | float | 0.8 ~ 1.3 | Perfect=0.8, Good=1.0, Late=1.3 |

**输出范围:** 0.16s（平抽 + Perfect）到 0.65s（扣杀 + Late）
**示例:** 扣杀 + Late = 0.5 × 1.3 = 0.65s

### 移动精度修正

```
MovementMultiplier = 1.0 - Clamp((CurrentSpeed - StandThreshold) / (SprintThreshold - StandThreshold), 0, 1) × 0.4
```

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 当前角色速度 | CurrentSpeed | float | 0 ~ 6 m/s | 角色在击球瞬间的移动速度 |
| 站定阈值 | StandThreshold | float | 固定 0.5 m/s | 低于此视为站定 |
| 冲刺阈值 | SprintThreshold | float | 固定 4.0 m/s | 高于此视为冲刺 |

**输出范围:** 0.6（全速冲刺）到 1.0（站定）
**示例:** 角色速度 2.0 m/s 时 = 1.0 - Clamp(1.5 / 3.5, 0, 1) × 0.4 = 1.0 - 0.17 = 0.83

## E. 边界情况

- **如果球路条件不满足（如扣杀时球在低位）**: 触发退化规则，扣杀退化为平抽。理由：保证玩家永远能打出一记球，操作不会"无响应"，但结果不是玩家想要的球路，形成"读对球的高度才能选择正确球路"的博弈维度。
- **如果玩家同时满足多种球路条件（如近网区域 + 后方向输入）**: 按优先级判断：先检查特殊条件（距网 < 2m → 网前球优先），再检查方向输入。理由：近网区域的特殊性优先于方向，因为网前球是"靠近网时的直觉操作"。
- **如果球从极低高度飞来（Y < 0.3m）且速度快**: 击球范围缩小（水平半径 ×0.7），因为低球需要更精确的站位。如果来不及进入缩小后的范围，触发 Miss。理由：低球本身就代表对手打出了好球，防守方需要付出更多代价。
- **如果角色在 Recovery 状态时球再次进入范围**: 球不会被击中，正常飞过。如果球落地则在对方半场判定为己方失分。理由：Recovery 是击球选择的代价，扣杀的 0.5s 硬直就是"高回报 = 高风险"的体现。
- **如果角色在 Stun 状态（Miss 后）时球仍在范围内**: 球不会被击中。Stun 结束后如果球还在飞行且仍在范围内，重新开启新的挥拍窗口。理由：Miss 的惩罚是 0.6s 硬直，球不太可能还在范围内（除非对手回了一个极慢的球）。
- **如果两个方向同时输入（如斜向触控）**: 取偏移量更大的轴为主方向。如果两个轴偏移量完全相等，优先取前后方向（前 > 后 > 左/右）。理由：触屏可能产生模糊输入，需要确定性消歧规则。
- **如果球以极高速度飞来（扣杀回球），挥拍窗口极短**: 挥拍窗口下限为 300ms（即使按正常公式算出更短）。理由：读招即玩法不等于反应速度测试，必须给玩家最低限度的决策时间。
- **如果角色站在球网正下方尝试击球**: 禁止击球。球网正下方（距中线 < 0.5m）为无效击球区域，球飞过网后才能击球。理由：符合羽毛球规则，防止"网前拦截"等不真实行为。
- **如果在挥拍窗口开启瞬间立刻按击球键（0ms 反应）**: 判定为 Good（窗口最早阶段），不判定为 Perfect。理由：Perfect 窗口在球距最佳击球点最近时，不是窗口开启时。这防止了"球一来就拍"的最优解策略。
- **如果角色属性力量修正使球速超过物理引擎承受范围**: 球速上限钳制为 30 m/s。理由：防止高速球穿透碰撞检测（30Hz 帧率下，30m/s 每帧移动 1m，不会穿透球场边界）。
- **Startup 阶段被打断**: 角色处于 Startup 状态时，如果对手的球飞入角色击球范围，引拍被中断，角色进入 Stun（200ms）。打断后不产出击球品质三元组，势系统根据"被打断"事件自行处理势头变化。理由：Startup 是可被更快的球压制的阶段，这是"快攻压制慢打"博弈的核心体现。
- **Swinging 阶段不可被打断**: Swinging 是揭示期的不可逆阶段，即使此时对手的球到达了击球范围，也不会中断。理由：揭示期已做出最终决策，打断会导致玩家失去对击球结果的控制感。
- **终结窗口内球高度不满足扣杀条件**: 当势系统触发终结窗口（奖励机制）时，终结扣杀忽略球高度条件，直接执行扣杀。理由：终结扣杀是势系统的奖励，应给予无条件执行的高光时刻，无需额外满足球高度要求。如果不满足扣杀高度，仍执行扣杀但球速可适当降低（×0.8）以体现非理想条件。

## F. 依赖

### 硬依赖（击球系统必须等待这些系统就绪）

| 依赖系统 | 依赖方向 | 说明 |
|----------|---------|------|
| 球场与球物理 | 上游 | 击球系统产出球的初速度和发射角，由球物理系统接管后续飞行。球物理提供球的实时位置和高度用于判定击球范围 |
| 角色移动 | 上游 | 击球系统需要角色的实时位置、速度来判断击球条件和移动修正。击球产出 Recovery 状态限制角色移动 |
| 时机窗口系统 | 上游 | 击球系统消费时机窗口的判定结果（Perfect/Good/Late/Miss），时机窗口负责定义窗口开启/关闭和最佳击球点 |

### 软依赖（击球系统可独立工作，但这些系统增强其体验）

| 依赖系统 | 依赖方向 | 说明 |
|----------|---------|------|
| 势系统 | 下游 | 击球系统产出击球品质三元组（球路类型、时机等级、移动状态），势系统消费并计算势头变化。击球系统不依赖势系统的任何输出。终结窗口由势系统触发，击球系统响应执行终结扣杀。 |
| 模糊起手 | 下游 | 击球系统的 Startup 阶段由模糊起手系统控制视觉表现（模糊期 + 渐明期），Swinging 阶段对应揭示期。模糊起手控制引拍动画的不确定性和时长，击球系统负责状态转换和打断判定。 |
| 反馈系统 | 下游 | 击球系统的时机结果和球路类型触发对应的反馈效果（震动、音效、特效） |
| Buff 系统 | 横向 | 可能通过 Buff 修改角色力量、速度等属性，间接影响击球参数。白盒阶段不涉及 |
| 回合与裁判 | 下游 | 击球系统的 Miss 可能导致球落地，触发裁判的得分判定 |

## H. 验收标准

- **给定** 角色站在己方半场中央（Idle 状态），**当** 球以正常弧线飞入击球范围（水平距离 1.0m，高度 1.2m），**则** 挥拍窗口开启，持续 500ms，时机环开始收缩动画
- **给定** 球进入击球范围且处于 Perfect 窗口（±50ms），**当** 玩家输入"后方向 + 击球键"，**则** 打出高远球，初速度 14 × 1.3 = 18.2 m/s，仰角 55°，产出三元组(Clear, Perfect, 站定)，方向偏移 0°
- **给定** 球在高位（Y = 2.0m）进入击球范围，**当** 玩家输入"下方向 + 击球键"，**则** 打出扣杀（满足球高度 > 肩高条件），初速度 22 m/s，仰角 -15°，硬直 0.5s
- **给定** 球在低位（Y = 0.6m）进入击球范围，**当** 玩家输入"下方向 + 击球键"（不满足扣杀高度条件），**则** 退化为平抽，初速度 18 m/s，仰角 10°
- **给定** 角色距网 1.5m，球进入击球范围，**当** 玩家按下击球键（无方向），**则** 打出网前球（满足近网条件），初速度 4 m/s，仰角 35°，落点在前场 5%~10%
- **给定** 角色以 3.0m/s 速度跑动中，球进入击球范围，**当** 玩家按下击球键，**则** 击球范围缩小为 0.9m，方向偏移增加 ±16°（15 × 2.0 移动惩罚），产出三元组中移动状态为"移动中"（MovementFactor = 0.8）
- **给定** 挥拍窗口已开启，**当** 窗口 500ms 结束后玩家仍未按键，**则** 触发 Miss，角色进入 Stun 状态持续 0.6s，不产出三元组
- **给定** 角色处于 Recovery 状态（刚完成扣杀 0.2s/0.5s），**当** 新球飞入击球范围，**则** 不触发新的挥拍窗口，角色无法击球，球正常飞过
- **给定** 球以扣杀速度（22 m/s）飞来，**当** 挥拍窗口按正常计算不足 300ms，**则** 窗口延长至最低 300ms
- **给定** 玩家输入斜方向（如左前方，两轴偏移量不同），**当** 前方向偏移量更大，**则** 判定为吊球（前方向优先于侧方向）
- **给定** 角色站在球网正下方（距中线 < 0.5m），**当** 球在范围内飞过，**则** 击球被禁止，不触发挥拍窗口
- **给定** Perfect 时机打出扣杀，**当** 球出手瞬间，**则** 触发 0.2s 慢动作（timeScale = 0.3），屏幕强震（强度 5/5），球初速度 28.6 m/s，产出三元组(Smash, Perfect, 站定)
- **给定** 挑球（Good 时机）打出后，**当** 球飞行结束落地，**则** 球落点在对手后场 75%~90% 深度，角色利用 1.3s~1.6s 飞行时间完成回位
- **给定** 角色处于 Startup 阶段（引拍中），**当** 对手的球飞入角色击球范围，**则** 引拍被打断，角色进入 Stun 状态持续 0.2s，不产出三元组
- **给定** 角色处于 Swinging 阶段，**当** 对手的球飞入角色击球范围，**则** 挥拍不被打断，正常完成击球判定
- **给定** 势系统触发终结窗口，**当** 球高度不满足扣杀条件（Y < 肩高），**则** 终结扣杀忽略高度条件直接执行，球速 ×0.8
