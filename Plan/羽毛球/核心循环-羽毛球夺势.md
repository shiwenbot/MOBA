# 羽毛球夺势 — 核心循环

## 30 秒循环（每次击球）

```
观察对手站位 → 读对手起手意图 → 预判球路 → 提前移动 → 时机击球 → 看结果反馈
```

每次击球包含四个阶段：

1. **信息获取**：对手站位偏向哪侧？引拍动作暴露了什么？
2. **决策**：我往哪跑？用什么球路回击？
3. **执行**：移动到位，在时机窗口内击球
4. **反馈**：击球音效 + 球轨迹 + 对手被迫跑位的视觉表现

手感目标：每次击球都有清晰的打击感——音效分层（轻弹→重击→扣杀），屏幕微震，球轨迹的速度感差异明显。

## 5 分钟循环（一个回合 Rally）

```
中立站位 → 互相试探 → 一方逐步夺势 → 站位崩溃 → 终结球 → 得分演出
```

回合叙事弧：

- **试探阶段**：双方打高远球，维持站位，观察对手习惯
- **升级阶段**：开始变化球路，一方逐渐失位
- **高潮阶段**：失势方拼命救球，夺势方寻找终结机会
- **终结**：扣杀或吊球得分，慢动作回放

"再来一局"的心理学：回合的叙事弧让玩家每次都觉得"下一回合我能读穿他"。

## Session 循环（一局比赛，15-30 分钟）

```
选角色 → 比赛（先到 21 分）→ 结算 → 再来一局
```

- 每分之间有短暂喘息（发球间隙）
- 比分接近时紧张感升级（局点/赛点特殊音效和视觉）
- 中场休息（11 分交换场地）提供自然退出点
- 结算页展示：得分热力图、夺势次数、最佳回合回放

## 进度循环（天/周）

- **段位系统**：青铜 → 白银 → 黄金 → 钻石 → 大师 → 王者
- **角色熟练度**：每个角色独立等级，解锁配色/称号
- **日任务**：完成 N 次扣杀、赢 N 场、连续夺势 N 次等

## 玩家动机

- **自主性**：每次击球都是开放选择——往哪打、怎么打、什么时候冒险。没有固定连招，博弈路径自由
- **胜任感**：从"乱按也能打回去"到"我读懂了你的习惯"的清晰成长曲线。时机反馈让进步可感知
- **关联性**：实时对手让每场博弈独一无二。AI 对手也有"性格"差异（激进型/防守型/多变型）
