# 羽毛球夺势 — 游戏概念文档

## 创意简报

一款手机端羽毛球对战游戏，核心体验是**紧张刺激的博弈对决**。玩家在每一次回合中读穿对手意图、精准回球、逐步夺取主动权，最终以一记致命扣杀终结回合。手感参考 Mario Tennis 的击球反馈，心理体验追求只狼式的心流与博弈爽感。

## 电梯演讲

一款让每次回球都是一次读招对决的羽毛球游戏——精准回球就是夺取主动权，对手站不住脚的那一刻，就是你的终结时刻。

## 核心幻想

我预判了你的预判。我每次回球都在逼迫你跑向错误的方向，直到你再也无法站稳。

## 独特卖点

像只狼对决一样的羽毛球——不是比谁反应快，而是比谁更会读招。完美防守本身就是进攻，"势"的争夺比分数更先分出胜负。

## MDA 分析

- **美学目标**: Challenge（博弈挑战感）+ Sensation（击球打击感）
- **动态**: 玩家通过击球选择迫使对手跑位 → 对手站位恶化 → 抓住空档终结。双方博弈形成"读招→反读"的对抗螺旋
- **机制**: "势"系统（站位压力累积）+ 模糊起手（不同球路引拍相似）+ 时机判定（完美回球夺势）

## 核心设计概念：「势」

羽毛球的每次击球不仅在回球，更在争夺站位主动权：

- **扣杀** → 迫使对手后退，远离网前
- **吊球** → 迫使对手前冲，暴露后场
- **平抽** → 维持快节奏，不给喘息
- **高远球** → 重置站位，买时间回位

当对手频繁被迫跑位、站位偏离中心时，就是"失势"。抓住失势的瞬间打出终结球，就是最爽的时刻。

这个系统跟只狼的架势条完全同构：
```
只狼：完美弹刀 → 消耗架势 → 架势崩 → 处决
羽毛球：精准回球 → 迫使跑位 → 站位崩溃 → 扣杀终结
```

额外的一层博弈：羽毛球挥拍的起手动作是模糊的——扣杀和吊球的引拍几乎一样，直到击球瞬间才暴露意图。这就是**读招层**。

## 参考游戏

- **Mario Tennis**: 击球手感、时机判定、角色差异化
- **只狼**: 对决节奏感、架势系统、心流体验、读招博弈
- **真实羽毛球**: 运动本身的站位博弈、变速突击、假动作

## 目标平台

手机（触屏操作）

## 核心操作模型（手机适配）

方向输入 + 单击球键：

| 操作 | 触发 | 球路 |
|------|------|------|
| 后方向 + 击球 | 高远球 Clear | 高弧线，争取回位 |
| 前方向 + 击球 | 吊球 Drop | 刚过网，调动前跑 |
| 下方向 + 击球（球在高位） | 扣杀 Smash | 极速下压，高风险高回报 |
| 侧方向 + 击球 | 平抽 Drive | 低平快速 |
| 近网 + 击球 | 网前球 Net | 贴网，技术球 |

## 预估规模

中。核心是单人对 AI 和联网 PVP 的对战体验，内容深度来自博弈而非内容量。

## 最大风险

- **读招博弈在低延迟下才有意义** → 帧同步技术要求高
- **手机操作精度** → 方向+击球的操作是否足够表达博弈深度
- **新手门槛** → 读招机制需要教学引导，否则新手只会乱按
