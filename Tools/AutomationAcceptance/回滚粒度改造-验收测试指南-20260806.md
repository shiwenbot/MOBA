## 1. 验收目标

改造后客户端只对**自己**做预测与回滚，其他玩家的权威状态进 `RemotePlayerBuffer`，不参与回滚重放。

必须同时证明三件事：

1. **一致时真的跳过了** —— 回滚计数不增、重放帧数为零
2. **跳过是安全的** —— S3 的哈希对账一致率不变、`HashNoRecordCount` 仍为 0
3. **别人没被牵连** —— 自己回滚时别人的位置仍是最新权威值

> 只验第 1 条会退化成一次纯性能优化。第 2 条是「跳过引入偏差但没人发现」的唯一防线。

## 4. 用例判据

| 用例 | 必须证明 |
|---|---|
| `consistent-snapshot-skips-rollback` | 一致快照应用后 `RollbackCount` 不增（不把 `LastRollbackReplayFrames` 当零值断言，该字段仅在回滚分支写入） |
| `consistent-snapshot-preserves-predicted-frame` | `LastPredictedFrame` 未回退到快照帧。**这条守的是最易错的一处**，回退会导致每个一致快照都重放一遍 |
| `consistent-snapshot-preserves-skill-graph` | 一致时进行中的技能状态仍在，`_skillGraphRuntime` 未被清 |
| `mismatch-snapshot-still-rolls-back` | 失配路径与改造前行为一致，`RollbackCount` 增、重放帧数正确 |
| `remote-players-not-in-world-state` | 应用含两玩家快照后 `worldState.PlayerCount == 1`，另一个在 `RemotePlayerBuffer` |
| `remote-players-survive-self-rollback` | **本阶段核心断言。** 自己失配回滚后，别人的位置仍是最新权威值，未被拨回旧帧 |
| `remote-player-removal-clears-buffer` | 快照里玩家消失后 buffer 同步移除 |
| `clear-world-state-clears-remote-buffer` | 重开局不残留上一局的别人 |
| `restore-self-only-keeps-single-body` | `RestoreSelfOnly` 后物理世界只有自己一个 body，别人的 body 未被 `PhysicsSnapshot` 带回 |
| `remote-body-mirror-survives-restore-self-only` | S8 在 `RestoreSelfOnly` 清理之后按最新权威远端状态重建 kinematic 镜像；镜像不进入 `_worldState` 或回滚快照 |
| `multi-snapshot-mixed-consistency-one-tick` | 同一 tick 连续「失配+一致」「一致+失配」两条序列，`LastPredictedFrame` 与回滚计数交叉正确 |

`prediction-self` 在当前 HEAD 应为 **106 条**（S6 完成时为 54 条）。`all` 输出 `Checks=4/4 Scenarios=5/5`。`--mode=validate` 输出 `Issues=0`。

## 5. 基线检查

S6 阶段的 `fixed-physics-bit-exact` 为 `0xD2120B5F0F5A5FE5`，在 S6 改动边界内必须不变。S8 将新增确定性字段纳入哈希后，当前 HEAD 基线为 **`0x4DBF74147B723F41`**。

## 7. 真机观测（项目负责人执行，不在 agent 范围）

无头测不出「看起来抖不抖」。用 S4 的注入设施：

1. 施加 150ms 双向延迟 + 5% 永久丢包，固定种子
2. 两个客户端同场，操作其中一个使其频繁失配
3. **观察点：自己发生回滚时，另一个玩家的球是否仍平稳** —— 改造前它会跟着被拨回旧帧再被下个快照拉回，表现为抖动
4. 记录 profiler 每帧耗时，与改造前同场景同种子对比

三项待回填：

- [ ] 改造前后每帧耗时对比数字
- [ ] 弱网下别人的球是否不再随本地失配抖动
- [ ] 真实网络下 `HashMismatchCount` 是否仍为 0

## 8. 失败排查

按优先级：

1. **一致时仍在重放** → 查 `ApplyAuthoritativeSnapshot` 里 `_lastPredictedFrame` 是否无条件回退到 `snapshot.FrameIndex`。这是最易错的一处，结果仍正确所以不报错，只是白跑
2. **技能突然中断** → 查 `_skillGraphRuntime.Clear()` 是否漏加 `if (mismatch)` 条件
3. **哈希一致率下降 / `HashMismatchCount` 非零** → 查 `_authoritativeSnapshots.Save` 是否被短路吞掉，或 `RestoreSelfOnly` 是否漏恢复了自己的某个字段
4. **别人的球消失** → 查 `SyncPlayerSpheres` 是否只改了别人那路而漏了自己，`_activePlayers` 必须含自己
5. **幽灵球残留** → `ClearWorldState` 补 `_remotePlayers.Clear()`
6. **物理世界有幽灵体** → `RestoreSelfOnly` 里若直接 `_physicsWorld.RestoreSnapshot(snapshot.PhysicsSnapshot)` 会把别人的 body 带回来，须按 `ToBodyId(selfPlayerId)` 过滤
7. **平滑抖动/每帧重启** → `CapturePredictionErrorAfterReconciliation` 被挪出了 `if (mismatch)`
8. **`fixed-physics-bit-exact` 偏离当前 `0x4DBF74147B723F41`** → 若没有新的世界态语义改动，按范围溢出处理；不要直接更新基线
